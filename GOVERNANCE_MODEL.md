# GOVERNANCE MODEL (Public Alpha Overview)

## Intent

Context Brain applies governance-minded boundaries between public and internal surfaces.

## Public-alpha principles

- Conservative read-first exposure.
- Explicit allowlists for public artifacts.
- No implicit promotion of internal surfaces to public contracts.

## Current boundary

- Public GPT Actions v1: read-only subset.
- Internal/generated API reference: openapi.json.

## Non-claims

- No claim that all internal governance workflows are part of public API scope.
